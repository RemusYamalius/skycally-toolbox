## School Timetable Generator — /tools/timetable-generator

A self-contained, browser-only wizard tool with 10-language support (including full Arabic RTL), school branding, conflict-aware timetable generation, and print/PDF/Excel export.

### Files to create
- `src/routes/tools.timetable-generator.tsx` — the entire tool (route + wizard + result + i18n object)
- `src/lib/tools.ts` — add entry: slug `timetable-generator`, category `utility`, icon `CalendarDays` (already imported), name "School Timetable Generator"
- `src/lib/related-tools.ts` — wire related tools
- `src/routeTree.gen.ts` — auto-regenerated by router plugin

No existing files/components are modified beyond the two registries above.

### Page structure (inside `ToolPageShell`)
1. "No data stored on our servers" badge under title
2. Language selector (top-right, top-left if AR) — flag emoji + name, 10 languages
3. Wizard progress bar: Step 1 → 2 → 3 → 4 → Result
4. Current step card (Next/Back, input validation)
5. `HowToUse` block
6. `ToolSeoContent` block (SEO title, description, 150–200 word body, 4 FAQs) — per project memory

### Step-by-step (matches spec exactly)
- **Step 1 — School Setup**: name, address/motto, academic year, logo upload (base64 via FileReader, preview), stamp upload (base64), days/week (5 or 6), periods/day (5–10), period duration (30/45/60), break period checkboxes.
- **Step 2 — Subjects & Teachers**: dynamic subjects with name, color picker, sessions/week, multiple teachers; delete button; summary list.
- **Step 3 — Classes**: dynamic classes; per-class subject checkboxes; per-subject teacher dropdown; delete button; summary table Class × Subject × Teacher.
- **Step 4 — Generate**: button + loading indicator. Algorithm distributes sessions evenly across week, avoids same-teacher-two-classes-same-slot conflicts (greedy with backtracking/retries), locks break periods, randomizes within constraints, shows warning if a constraint is unsatisfiable.
- **Result**: tab per class; grid rows=periods, cols=days; cells show subject + teacher with subject color; break cells neutral with "— Break —"; school header (logo | name | address | year | stamp) above grid.

### Export
- **Print**: `window.print()` with `@media print` CSS that hides UI chrome and shows only header + current class grid; header repeats per page via `thead`/page-break rules.
- **Export PDF (current class)**: jsPDF + jspdf-autotable via CDN (`loadScript` from `src/lib/cdnScript.ts`), embeds logo/stamp.
- **Export Excel**: SheetJS via CDN, one sheet per class.
- **Export All PDF**: one PDF, one page per class.

### Internationalization
- Single `translations` object keyed by lang code containing every UI string (labels, buttons, placeholders, errors, step titles, day names, "Break", export labels, etc.).
- `lang` state in React; switching re-renders all strings instantly.
- For `ar`: set `dir="rtl"` on the tool root wrapper, mirror grid (CSS uses logical properties / `direction: rtl`), header layout mirrors, language selector moves to top-left; exported PDF uses right-aligned columns and RTL text where applicable (jsPDF supports `align: "right"`).
- Languages: EN, FR, AR, ES, PT, DE, TR, ID, SW, RU.

### Design
- Dark theme via existing semantic tokens (no raw colors in JSX).
- Card-based wizard, one visible step at a time, animated progress bar using existing `Progress` component.
- Color-coded subject cells (inline `style={{ backgroundColor }}` from user-chosen color — necessary user data, not theme).
- Responsive: stacked layout on mobile, grid on desktop.

### Technical notes
- 100% client-side. No server functions. No new npm deps — jsPDF/autotable/xlsx loaded from CDN via existing `loadScript` helper.
- Logo/stamp stored as base64 data URLs in component state.
- All English-only source strings; translations live in the structured object as required.
