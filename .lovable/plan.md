
## World Radio — /tools/world-radio

A Radio Garden–style explorer with an interactive world map of live radio stations, a searchable/filterable list, and a persistent bottom player. 100% client-side, no backend.

### Files

**Create**
- `src/routes/tools.world-radio.tsx` — entire tool (route + UI + state + API calls + Leaflet integration)

**Edit (registries only)**
- `src/lib/tools.ts` — add entry: slug `world-radio`, name "World Radio", category `utility`, icon `Radio` from lucide-react
- `src/lib/related-tools.ts` — wire related tools (e.g. `network-speed-test`, `ip-address-lookup`, `qr-generator`)
- `src/routeTree.gen.ts` — auto-regenerated by the router plugin

No existing components are modified.

### Page structure (inside `ToolPageShell`)

1. `ToolPageShell` (title + description; the shell's "No files are stored on our servers" badge already renders under the title — no duplicate added)
2. Main split workspace
   - **Desktop ≥ md**: left panel 40% (search + filters + station list + Favourites tab), right panel 60% (Leaflet map). Height ~`70vh`.
   - **Mobile**: map on top (50vh), list below.
3. Fixed **bottom player bar** (semi-transparent dark with `backdrop-blur`) — pinned via `fixed bottom-0 inset-x-0 z-40`. Adds bottom padding to `ToolPageShell` content so the bar doesn't cover SEO blocks.
4. `HowToUse` block
5. `ToolSeoContent` block (SEO title, ~150–200 word body, 4 FAQs) — required by project memory

### Left panel

- Tabs: **All** / **Favourites**
- Search input — debounced 300 ms; matches by name, country, or tag client-side over loaded stations; if query length ≥ 3 and zero local matches, fetch `/stations/byname/{q}` to expand results
- Filter row: country `<Select>` (populated from `/countries`), tag `<Select>` (News, Music, Pop, Rock, Jazz, Classical, Talk, Sports, Religion, Culture), language `<Select>`, sort `<Select>` (Popularity / Name / Bitrate)
- Default list: top 100 from `/stations/topvote/100`, sliced to 50 visible with "Show more"
- Each row: favicon (fallback to `Radio` icon on error), name, country + flag emoji (derived from `countrycode`), tag badge, heart toggle, bitrate
- Active station highlighted with green border/background
- Clicking a row → `playStation(s)` → map `flyTo([s.geo_lat, s.geo_long], 6)` + pulse animation on its marker

### Map (Leaflet)

- Leaflet JS + CSS + MarkerCluster loaded via existing `loadScript` (`src/lib/cdnScript.ts`) and a small `loadStylesheet` helper added inline in the route file (creates a `<link>` once)
- Tiles: `https://{s}.basemaps.cartocdn.com/dark_all/{z}/{x}/{y}{r}.png`
- Each station with valid `geo_lat`/`geo_long` → a `L.circleMarker` (radius = `clamp(3, log(votes+1) * 1.5, 10)`, fill `#00ff88`, stroke `#00ff88`, glow via CSS class with `filter: drop-shadow`)
- Wrapped in `L.markerClusterGroup()` (cluster icons themed dark+green)
- Marker click → popup (name, country, tag, bitrate) + `playStation`
- Active station → extra `L.circle` with CSS-animated pulse (radius animates, opacity fades) re-added on each change
- Geolocation: `navigator.geolocation.getCurrentPosition` on mount → `map.setView([lat, lng], 4)`; fallback `[20, 0]` zoom 2; user prompt errors handled silently

### Bottom player bar

- Shows favicon, name, city + country, tag badge, bitrate (`{kbps} kbps`), buffering spinner (when `<audio>` is in `waiting` state), play/pause, volume slider, "Add to favourites" heart
- HTML5 `<audio>` ref; `src` set to `station.url_resolved`
- On `error` event: show toast "Stream unavailable, try another station"; auto-retry once after 1.5 s by re-setting `src`
- On play: fire `GET /url/{stationuuid}` (fire-and-forget) to register the click stat

### Favourites

- Stored in `localStorage` under key `world-radio:favourites` as an array of station UUIDs + denormalized snapshot (name, url_resolved, favicon, country, tag, bitrate, geo)
- Heart toggle adds/removes
- Favourites tab lists them; drag-to-reorder via native HTML5 drag events (no extra dep); persists order

### API

Base: `https://de1.api.radio-browser.info/json`. All `fetch` calls include `headers: { 'User-Agent': 'Skycally/1.0' }` (note: browsers may silently strip `User-Agent`; included as requested — no fallback needed). Endpoints used: `/stations/topvote/100`, `/stations/byname/{q}`, `/stations/bycountryexact/{country}`, `/stations/bytag/{tag}`, `/countries`, `/url/{uuid}`.

Stations without `url_resolved`, `geo_lat`, or `geo_long` are filtered out before mapping; non-geo stations still appear in the list.

### Design

- Skycally dark theme via existing semantic tokens (no raw colors in JSX except the brand green `#00ff88` used for map markers, which is necessary canvas/SVG styling, not a theme token; defined once at the top of the file as `const ACCENT = "#00ff88"`)
- Map dot CSS class (`leaflet-glow-dot`) + pulse keyframes injected via a single `<style>` block in the route (Leaflet markers can't use Tailwind)
- Player bar: `bg-background/70 backdrop-blur border-t border-border`
- Station cards: `bg-card border-border` with green hover ring
- Framer-motion for tab + panel transitions
- Fully responsive (md breakpoint splits layout; mobile stacks)

### Technical notes

- 100% client-side. No new npm deps — Leaflet, MarkerCluster, and their CSS loaded from CDN
- SSR-safe: all Leaflet usage inside `useEffect` (guarded by `typeof window !== 'undefined'`); map container ref only initialized after mount
- All UI strings in English (project memory)
- Cleanup on unmount: stop audio, remove map instance
